# Бэкенд + админка сайта «Айсберг»

Простая и защищённая панель управления контентом и SEO для нового сайта iceberg.spb.ru.
Стек — **PHP 8.1+ и SQLite**, без внешних зависимостей: «залил папку — работает».

- **Что редактируется:** заявки с форм · SEO (title, description, OG, canonical/robots) · заголовки H1 ·
  тексты и фото на главной · содержимое внутренних страниц · оффер посадочной производства ·
  тексты политики и cookie · глобальные телефон и почта. Всего 11 страниц.
- **Как это работает:** сайт остаётся статикой; тонкий PHP-слой **накладывает** правки из базы на
  эталонный HTML и **кэширует** результат. Не тронутое в админке отдаётся байт-в-байт как раньше —
  SEO не страдает (проверяется автоматически, см. DEPLOY.md §7).
- **Защита:** пароль (argon2id) + 2FA + второй заслон на сервере + анти-перебор + CSRF + строгие заголовки.
  Подробно — [SECURITY.md](SECURITY.md).
- **Форма заявки не редактируется намеренно** — в ней согласие 152-ФЗ, ловушка для ботов и адрес
  обработчика: случайная правка сломала бы приём заявок.

## Быстрый старт (на сервере или локально с PHP)
```bash
cp app/config.example.php app/config.php     # заполнить пути, BASE_URL, APP_SECRET
php bin/check_env.php                          # проверить окружение (потом удалить)
php bin/install_layout.php                      # разложить эталоны страниц (после копирования dist/)
php bin/create_admin.php                        # создать администратора
php bin/seed.php                                # завести страницы, сверить эталоны
php bin/check_deploy.php                        # предполётная проверка: что готово, что блокирует запуск
php bin/check_seo.php --live https://iceberg.spb.ru   # сверка склейки с живым сайтом
# открыть сайт и /admin/ — войти, при первом входе привязать 2FA
```

## Как расширять
- **Новое текстовое поле** — обернуть фрагмент в `dist/` маркером `<!--cms:КЛЮЧ-->…<!--/cms:КЛЮЧ-->`
  (через `tools/cms_markers.py`, чтобы разметка не разъехалась) и добавить запись
  в `PageRegistry::pages()`. Поле само появится в админке.
- **Новое фото** — если это блок с фоном-заглушкой, поле типа `css_image` с CSS-селектором:
  бэкенд подставит `background-image` отдельным блоком стилей, вёрстку не трогая.
- **Новая страница под управление** — добавить в `PageRegistry::pages()` (адрес, файл, поля)
  и перезапустить `bin/install_layout.php`.
- После любой правки вёрстки в `dist/`: `cms_markers.py` → `install_layout.php` → `check_deploy.php`.

## Что осталось до боевого запуска
1. Настроить SMTP в `dist/mail-config.php` (сейчас заглушки — письма с заявками не уйдут).
2. Вставить текст политики конфиденциальности и соглашения о cookie — прямо в админке.
3. Залить на хостинг по [DEPLOY.md](DEPLOY.md) и прогнать `bin/check_deploy.php`.
