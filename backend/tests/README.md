# Проверки админки

Локально на машине PHP нет, поэтому стенд поднимается на **переносимой сборке PHP**
(один бинарник, ничего не устанавливается в систему), а проверки ходят по админке
через HTTP — ровно как браузер, с cookie, CSRF и настоящим кодом 2FA.

## Как прогнать

```bash
# 1. Один раз: взять переносимый PHP (нужны pdo_sqlite и gd)
curl -sL -o php.tar.gz https://dl.static-php.dev/static-php-cli/common/php-8.3.9-cli-macos-aarch64.tar.gz
tar xzf php.tar.gz                       # появится бинарник ./php

# 2. Поднять стенд на текущей сборке сайта
ICEBERG_PHP=$PWD/php ./tests/stand.sh

# 3. Прогнать проверки
ICEBERG_PHP=$PWD/php python3 tests/smoke.py
```

Стенд по умолчанию разворачивается в `/tmp/iceberg-stand` и не трогает ни `dist/`, ни рабочие файлы.

⚠️ Прогон рассчитан на **свежий стенд**: он оставляет после себя тестовые правки, и второй запуск
подряд без `stand.sh` даёт ложные провалы. Перед каждым прогоном поднимайте стенд заново.

⚠️ Брать сборку из папки **`common`**, а не `bulk`: в bulk-сборке при большем числе расширений
**нет `pdo_sqlite`** — без него база не поднимется. Проверить сразу:
`./php -r "var_dump(extension_loaded('pdo_sqlite'), extension_loaded('gd'));"`

## Что проверяется

1. Вход в админку: пароль → 2FA → рабочий экран.
2. Все 11 управляемых страниц открываются, поля подтянуты из вёрстки.
3. **«Сохранить, ничего не изменив» не создаёт правок** — иначе админка потихоньку
   переписывала бы страницы сама.
4. Правки главной (текст, SEO, фото) доходят до сайта, шейдер и вёрстка целы.
5. Оффер посадочной (он задаётся скриптом) подменяется, объект `OFFERS` не ломается.
6. После правки текста внутренней страницы **форма заявки, согласие 152-ФЗ и ловушка
   для ботов остаются на месте**.
7. Смена телефона и почты меняет основной контакт и **не трогает контакты отдела кадров**
   на странице вакансий.
8. Заявки: читаются из журнала форм, не задваиваются при повторном заходе, статусы, CSV.
9. Публичная часть: все страницы 200, несуществующая — 404.

Отдельно, вручную (см. DEPLOY.md §7): страницы без правок отдаются **байт-в-байт** как эталон,
и объединённый `.htaccess` проверялся на настоящем Apache.
