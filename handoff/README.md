# iceberg.spb.ru — новый сайт (пакет для переноса)

Готовый к заливке сайт группы компаний «Айсберг» и инструкции по переезду с WordPress.
Обновлён 31 августа 2026.

В пакете, кроме статики, есть **один PHP-файл** — обработчик форм `site/send.php`
(отправляет заявки почтой). Админки/CMS в пакете по-прежнему нет.

## Что внутри

| Папка | Что это |
|---|---|
| `site/` | **Боевой web-root.** Содержимое этой папки заливается в корень сайта (`public_html`) как есть |
| `docs/perenos-sayta.html` | **Инструкция по переезду**: карта адресов, редиректы, robots.txt, порядок переключения, проверка, откат |

## Порядок работ (коротко)

1. **Бэкап текущего сайта** — файлы + дамп базы WordPress. Это условие безопасного отката.
2. **Залить содержимое `site/`** в корень сайта. Файл `site/.htaccess` — обязателен, в нём все редиректы;
   он скрытый, проверьте, что FTP-клиент его не пропустил.
3. **Прописать доступы к почте** в `site/mail-config.php` — см. раздел «Формы и почта» ниже.
   Без этого формы будут отвечать «не удалось отправить».
4. **Отключить WordPress** — убрать файлы движка из корня, закрыть админку.
5. **Проверить по чек-листу** из `docs/perenos-sayta.html`, раздел 06.
6. **Яндекс.Вебмастер** — добавить `sitemap.xml`, отправить главные страницы на переобход.

Полная версия с объяснениями — в `docs/perenos-sayta.html` (откройте в браузере).

## Требования к хостингу

- Apache с `mod_rewrite` (есть на sprinthost по умолчанию).
- **PHP 8.1 и новее** — нужен только для формы заявки (`send.php`). Всё остальное — статика:
  если PHP отключить, сайт продолжит работать, перестанут уходить только заявки.
- Место: ~12 МБ.

## Формы и почта

Заявки с форм уходят на `send.php`, он отправляет письмо через SMTP вашего почтового ящика.

1. Откройте `site/mail-config.php` — сейчас там **заглушки**:
   `smtp.example.com`, `CHANGE_ME_SMTP_PASSWORD`.
2. Подставьте настоящие данные ящика (sprinthost: «Почта» → ящик → «Настройки почтовых программ»):
   `host`, `port`, `secure`, `username`, `password`.
3. В `from.email` укажите адрес **на том же домене**, что и SMTP-ящик, иначе письма уйдут в спам.
   В `to` — куда складывать заявки (по умолчанию `iceberg@iceberg.spb.ru`).
4. Отправьте тестовую заявку с сайта и убедитесь, что письмо пришло.

Каждая заявка дополнительно дописывается в `site/leads.log` **до** отправки письма —
если почта временно не работает, лид не потеряется. `mail-config.php`, `leads.log` и `lib/`
закрыты от посторонних в `.htaccess`.

Передачи заявок в CRM пока нет — это отдельный шаг.

## Требования закона (152-ФЗ)

- В каждой форме есть **чекбокс согласия** на обработку персональных данных,
  по умолчанию не отмечен; без него заявка не отправляется.
- На всех страницах — **всплывающее уведомление о cookie**.
- Обе ссылки ведут на `policy.html` и `cookie_agreement.html`. **Страницы пока пустые** —
  как будет текст Политики и Соглашения, мы их наполним и откроем для индексации.

## Важно

- **Адреса страниц менять нельзя.** Весь смысл переезда в том, что URL остаются прежними —
  так сайт сохраняет позиции в поиске. Любое переименование папки в `site/` ломает склейку.
- **Страницы `technicheskie-tkani/` и `emdi/`** — временные копии старых, чтобы при смене движка
  ничего не пропало. Их переделка — отдельная задача.
- Инструкция `docs/perenos-sayta.html` описывает переезд статики; про `send.php` и настройку
  почты там пока ничего нет — этот раздел README её дополняет.

## Проверка после заливки

```bash
for u in / /shveinoe-proizvodstvo/ /contacts/ /policy.html /trikotazhnie-polotna/100/ /robots.txt /sitemap.xml; do
  printf "%-34s" "$u"
  curl -s -o /dev/null -w "%{http_code} %{redirect_url}\n" "https://iceberg.spb.ru$u"
done
```

Ожидаемо: страницы — `200`, `/trikotazhnie-polotna/100/` — `301` на `https://biflex.tkany.com/`.
Отдельно проверьте, что `https://iceberg.spb.ru/mail-config.php` отдаёт **403 или 404**, а не текст файла.
